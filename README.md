## 🧭 How my work is different

Most student projects stop at "it works on my machine." I try to build past that line.

- **I start from a real problem.** I build tools I'd actually use: for finding internships, for navigating dense legal text, for coding together in real time.
- **I care about trust, not just output.** In my AI work, I'd rather a system say *"I don't have evidence for this"* than confidently make something up. Grounded answers, cited sources, honest uncertainty.
- **I think in full systems.** Auth, access control, data models, deployment, and the UI someone has to actually use. Not just one clever piece.
- **I ship.** Containers, cloud deploys, and live demos over screenshots.

Plenty of people build apps with an LLM bolted on. I'm more interested in the part after that: making it reliable, explainable, and worth depending on.
